# Щоденник тренувань

Простий PWA-щоденник для спортзалу: вправи, підходи, історія, особисті рекорди. Працює офлайн, дані зберігаються на телефоні.

**Відкрити:** https://sevvykx.github.io/gym-diary/

## Встановлення на iPhone
1. Відкрити посилання вище в Safari.
2. «Поділитися» → «На початковий екран».
