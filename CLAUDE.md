# Щоденник тренувань (PWA)

PWA-щоденник тренувань для спортзалу. Встановлюється на iPhone через Safari → «На початковий екран», працює офлайн. Друзі встановлюють за посиланням (GitHub Pages).

## Стек
- Чистий HTML + CSS + JS (ES-модулі). **Без збирача, без npm, без фреймворків.** Node.js на машині немає.
- Єдина бібліотека: **Dexie.js**, локальна копія в `vendor/dexie.mjs` (не CDN, для офлайну).
- Навігація: hash-роутер у `js/app.js` (`#/workout`, `#/history/7`).
- Офлайн: Service Worker `sw.js` у корені, кеш з номером версії (міняти версію при кожній зміні файлів).
- Хостинг: GitHub Pages.

## Запуск локально
```bash
python3 -m http.server 8000
```
Відкрити http://localhost:8000 (у DevTools режим iPhone). ES-модулі не працюють через `file://`.

## Структура
- `index.html`: iOS meta-теги, верхня панель, `<main id="view">`, нижня навігація
- `css/styles.css`: темна тема (змінні в `:root`), safe-area відступи, компоненти
- `js/app.js`: точка входу, роутер
- `js/db.js`: схема Dexie, стартові вправи, `navigator.storage.persist()`
- `js/seed.js`: стартовий список вправ
- `js/utils.js`: допоміжні функції (`escapeHtml` для будь-якого тексту користувача в innerHTML)
- `js/views/*.js`: по файлу на екран; кожен експортує `render(el, param)`
- `icons/`, `manifest.webmanifest`, `sw.js`: PWA

## Схема даних (Dexie)
```js
db.version(1).stores({
  exercises: '++id, &name, muscleGroup',   // { name, muscleGroup, isCustom }
  workouts:  '++id, startedAt',            // { startedAt, finishedAt|null, exerciseIds: [] }
  sets:      '++id, workoutId, exerciseId' // { workoutId, exerciseId, weight, reps, createdAt }
});
```
- Активне тренування: останнє за `startedAt` з `finishedAt === null`.
- Рекорди рахуються на льоту: макс. вага; найкращий підхід за Еплі `w * (1 + r/30)`; для ваги 0 це макс. повторів.
- Експорт: `{ app: 'gym-diary', version: 1, exportedAt, exercises, workouts, sets }`. Імпорт замінює всі дані в одній транзакції після підтвердження.

## Правила
- Інтерфейс тільки українською.
- Mobile-first під iPhone: темна тема, великі кнопки (≥48px), нижня навігація, safe-area.
- Поля вводу з `font-size ≥ 16px` (інакше iOS зумить).
- Код чистий і простий, короткі коментарі лише в складних місцях. Без зайвих бібліотек.
- Працюємо по одному кроку. Після кроку: коротко що зроблено, як перевірити в браузері, команда для git-коміту. Комітить користувач сам.
- Користувач **не хоче пояснень термінів наперед**, лише відповіді на його питання та розбір помилок.
