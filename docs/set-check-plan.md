# План: галочки підходів, таймер відпочинку, нотатки

Гілка: `set-check`. Після кожного кроку відмічай `[x]` і пропонуй commit.
Орієнтир за поведінкою: застосунок Hevy (екран запису тренування).

## Що робимо
Картка вправи стає таблицею підходів: № · минулого разу · кг · повтори · ✓.
Рядки існують наперед, галочка позначає виконані. Після галочки запускається
таймер відпочинку цієї вправи. До вправи можна написати нотатку.

## Рішення
- Кнопки «−» і «+» біля ваги й повторів зникають: числа вводяться з цифрової
  клавіатури прямо в рядку. Новий рядок копіює значення попереднього.
  «Повторити попередній підхід» теж зникає.
- Невідмічені підходи при завершенні тренування не зберігаються (з підтвердженням).
- Відпочинок спочатку ВИМКНЕНИЙ для кожної вправи (як у Hevy). Вмикається кнопкою
  в картці, час виставляється барабанами і запам'ятовується для цієї вправи.
- Таймер відпочинку і таймер у «Годиннику» (js/clock.js) один і той самий:
  галочка запускає його на час вправи, смужка знизу показує той самий відлік.
- Нотатка належить вправі в конкретному тренуванні, а не вправі назавжди.

## База (version 3)
- sets.done: підхід виконано. Міграція ставить старим підходам done: true.
- exercises.restSeconds: відпочинок для вправи (немає або 0 = вимкнено).
- workouts.notes: { exerciseId: текст }.
- Файл копії version 3; копії 1 і 2 імпортуються, підходи стають виконаними.
- У завершених тренуваннях лежать лише виконані підходи, тому історія, головна
  і «минулого разу» done не перевіряють. Перевіряють рекорди й екран тренування,
  бо вони бачать активне тренування.
